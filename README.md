### 🎬 Recriando o site da Netflix

Fiz esse projeto pra treinar e mostrar minhas habilidades em HTML e CSS.
A ideia foi recriar a tela inicial da Netflix, trazendo o visual e a experiência o mais próximos possível do original, mas com um código limpo e bem estruturado.

Quis entender de perto como uma interface tão popular é construída e colocar em prática o que venho aprendendo sobre layout, desenvolvimento web e experiência do usuário.

### 💡 O que usei

HTML5

CSS3

Flexbox e Grid Layout

Design Responsivo

### 🎨O que tem de interessante

✨ Layout inspirado no site da Netflix
✨ Menu superior com seletor de idioma
✨ Campo de login com validação de e-mail
✨ Imagem de fundo e chamada principal centralizada
✨ Interface leve e bem organizada
